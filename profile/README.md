## 🚀 What is MyDevStack?

MyDevStack is your **local AWS playground** — a developer-friendly GUI that brings AWS services to your localhost. No cloud bills, no latency, no setup headaches. Just pure local development joy.

Build, test, and debug your AWS applications entirely on your machine using popular emulators like **LocalStack**, **FloCi**, or **MiniStack**.

## 🛠️ Supported AWS Services (15+)

MyDevStack gives you a visual interface for managing local AWS services:

| Category | Services |
|----------|----------|
| **Storage** | 🪣 S3 |
| **Compute** | ⚡ Lambda, 🐳 ECS, 🛳️ EKS |
| **Database** | 🗄️ DynamoDB, 🐘 RDS, 🧊 ElastiCache |
| **Messaging** | 📨 SQS, 🔔 SNS, 📧 SES |
| **API & Network** | 🌐 API Gateway (REST + HTTP) |
| **Security** | 🔑 IAM, 🔐 KMS, 🛡️ Secrets Manager |
| **Monitoring** | 📊 CloudWatch |
| **Developer Tools** | 📝 Parameter Store, 🎯 EventBridge |

...and counting! New services added regularly.

## 🔌 Emulator Compatibility

MyDevStack works seamlessly with:

- 🟢 **[LocalStack](https://localstack.cloud/)** — Full-featured AWS emulator
- 🟡 **[FloCi](https://floci.io/)** — Lightweight alternative
- 🔵 **[MiniStack](https://ministack.org/)** — Minimal footprint option

Configure your emulator endpoint once, and MyDevStack handles the rest.
